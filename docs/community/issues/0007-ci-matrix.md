## 背景

本地只在 Python 3.14 上验证过，而 README 声称支持 3.10+。
需要 CI 矩阵覆盖 3.10、3.11、3.12，避免类型标注或标准库差异导致失败。

## 讨论

> **维护者**（2026-11-05）
>
> 不引入第三方 lint 依赖；CI 只跑 `unittest`、`compileall` 和示例扫描。
> 这样 fork 后的贡献者不需要额外安装工具。

> **评审（自检）**（2026-11-05）
>
> 示例扫描预期退出码是 1（因为存在高危问题），CI 里要显式允许，
> 否则会把“检测到漏洞”误判为构建失败。

## 结论

PR #6 合并。CI 三版本矩阵通过；README 徽章更新为“30 tests passing”。
