- 关闭：2026-10-16

- 关联 PR：#3

## 背景

终端输出适合开发，但课程展示和审计归档需要一个可截图、可筛选、可离线打开的
单文件报告。要求：

- 不依赖外部 CDN、字体或图片；
- 展示风险分、等级分布、证据与修复建议；
- 支持按等级筛选；
- 能在 CI 中作为 artifact 保存。

## 讨论

> **维护者**（2026-10-10）
>
> 用内联 CSS/JS，避免报告在离线环境打开时样式丢失。风险分只是趋势指标，
> 必须在页脚明确“不能替代人工审计”。

> **评审（自检）**（2026-10-14）
>
> HTML 必须转义源码证据，否则合约里的 `<`、`>` 会破坏页面；
> 空结果也要有正常状态，而不是空白页。

## 结论

PR #3 合并，新增 `render_html()` 与 `test_reports.py`。
报告在 1440px 宽度下可直接截图，作为课程材料。
