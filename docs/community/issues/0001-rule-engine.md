## 背景

课程项目需要从零建立一个可运行的静态分析核心，而不是只写文档。第一版至少应能：

1. 递归发现 Solidity 文件；
2. 剥离注释并定位函数；
3. 对重入和 `tx.origin` 给出带行号的发现；
4. 有可复现的 vulnerable / clean 样例。

## 讨论

> **维护者**（2026-09-20）
>
> 不引入第三方依赖，保证在 Windows 机房环境也能直接运行。规则先少而准，
> 第一版只做 3 条，后续按 issue 增量补充。

> **评审（自检）**（2026-09-24）
>
> 函数切片用花括号配对即可，不需要完整 AST；但必须保留原始行号。
> 样例中要包含一个“看起来危险、实际安全”的 Checks-Effects-Interactions 版本，
> 否则无法证明规则不是简单关键词匹配。

## 结论

PR #1 合并，v0.1.0 发布。首版覆盖 SS-101、SS-102、SS-103，
并建立 `examples/vulnerable` 与 `examples/clean` 两套样例。
