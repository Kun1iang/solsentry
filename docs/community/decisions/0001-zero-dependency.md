# ADR-0001：零运行时依赖

- 状态：accepted
- 日期：2026-09-22
- 决策者：维护者

## 背景

课程项目需要在 Windows 机房、个人笔记本和 CI 上都能直接运行。目标用户包括
不熟悉 Python 虚拟环境的同学与需要快速接入 CI 的开发者。

候选方案：

1. 使用 `rich` / `click` / `pytest` 等第三方库，开发体验更好；
2. 只使用 Python 标准库，牺牲部分便利性，换取零安装成本；
3. 提供 Docker 镜像，隔离环境。

## 决策

选择方案 2：运行时与测试都只使用标准库。

## 理由

- `python -m solsentry` 无需 `pip install` 即可运行；
- CI 不需要缓存依赖，fork 后的贡献者也不会被环境问题卡住；
- 课程展示环境可能无法联网安装包；
- 标准库的 `argparse`、`unittest`、`json` 足以覆盖当前需求。

## 代价

- 终端颜色、表格对齐需要手写；
- 测试发现与断言不如 pytest 方便；
- 未来若需要 AST 解析，可能需要引入 `solc`/`slither`，届时以**可选适配器**的方式接入，
  不破坏核心零依赖。

## 结果

- `pyproject.toml` 中 `dependencies = []`；
- CI 不安装第三方包；
- README 明确“零运行时依赖”。
