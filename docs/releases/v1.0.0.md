# SolSentry v1.0.0

发布日期：2026-11-08  
许可证：MIT  
标签：[`v1.0.0`](https://github.com/Kun1iang/solsentry/releases/tag/v1.0.0)

## 亮点

- **7 条规则**：重入、`tx.origin`、低级调用未检查、动态 `delegatecall`、
  弱随机数、`selfdestruct`、敏感函数缺权限。
- **5 种输出**：终端、JSON、Markdown、HTML、SARIF 2.1.0。
- **30 个测试**：覆盖规则命中/未命中、抑制、CLI、报告结构。
- **零运行时依赖**：Python 3.10+ 标准库即可运行。
- **CI 矩阵**：GitHub Actions 覆盖 Python 3.10 / 3.11 / 3.12。

## 升级说明

从 0.5.0 升级：

- 风险分权重调整为 critical=30、high=12、medium=4、low=1；
- HTML 报告改为单文件、无外部资源；
- `--fail-on` 默认值仍为 `high`，行为不变；
- 新增 `--format sarif` 与抑制注释。

## 已知限制

- 不解析继承、内联汇编与跨函数数据流；
- 规则是启发式匹配，需人工复核；
- 不做 PoC 执行、不连接链、不处理私钥。

## 验证

```text
$ python -m unittest discover -s tests -v
Ran 30 tests in 2.0s
OK

$ PYTHONPATH=src python -m solsentry scan examples/clean --fail-on high
exit code 0

$ PYTHONPATH=src python -m solsentry scan examples/vulnerable --fail-on high
exit code 1
```
